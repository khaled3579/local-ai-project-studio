المتطلبات: Windows x64 وPython 3.13 x64 مثبت مع pip وvenv وTkinter وإتاحة الأمر python، وتعريف NVIDIA المناسب عند استخدام GPU.
تُجهّز بيئة Python جديدة تخص هذا المجلد تلقائيًا، بالاعتمادات المقفلة المرفقة ودون تنزيل عجلات من الشبكة. لا تُنقل .environments من مجلد آخر.

تتضمن هذه النسخة ملفات البرنامج وواجهاته ومشغلاته، ومحرك llama وNode وChromium وأدوات التحليل وعجلات Python وتراخيصها.
أُبقيت أدوات الفحص التي يستخدمها البرنامج لأنها وظائف تشغيل أساسية، ولم تُنسخ تقارير التجارب أو المشاريع التجريبية أو السجلات القديمة.

إعدادات النموذج الحالية ومجلد نماذجك منقولة في daily/settings.json وdaily/model-library.json. تبقى أوزان GGUF وملف الرؤية في مجلدها الأصلي على G:\lm_studio_models ولا تُنسخ إلى هنا. يمكنك تغييرها من مكتبة النماذج.
لم تُنسخ محادثات المشاريع أو مرفقاتها إلى تثبيت البرنامج. اختر مجلد مشروعك الحالي من الواجهة لاستعادة بياناته الموجودة في .local-ai داخل مجلده. لا تنسخ مجلد مشروع داخل مجلد البرنامج نفسه.

البيانات التي ينشئها البرنامج لاحقًا: daily للإعدادات والسجلات، و.environments لبيئة Python، و.updates للنسخ الاحتياطية. لا تحذف بيانات مشروعك أو أوزان النموذج عند تنظيف البرنامج.
تفاصيل الصيانة والترقية والرجوع: PACKAGE_README_AR.txt.


الإصدار 4.7.0 — أدلة قبول المتطلبات:
قبل اعتماد تسليم المشروع، تُربط متطلبات الطلب الحالي والملخص الحالي بمعايير قابلة للفحص واختبارات مسماة نُفذت فعلًا. يُرفض الدليل الناقص أو القديم والاختبار المتخطّى أو الاسم المكرر غير المميز. تبقى مراجعة ملاءمة الاختبارات وشمولها ضرورية؛ الربط لا يثبت المعنى تلقائيًا.
تُحفظ الخطة في .local-ai/acceptance-plan.json والتقرير في .local-ai/delivery-evidence.json. يعرض زر «أدلة القبول» تفاصيل آخر تقرير للمهمة. تُلغى صلاحية الخطة عند تغير الطلب أو مراجعة المتطلبات، وتحتاج أدلة المتصفح إلى إعادة تحميل بعد تعديل المصدر.
نجاح الفحص اليدوي وحده يمثل نجاح الفحص؛ تسليم المساعد يحتاج اجتياز بوابة قبول المتطلبات أيضًا. تبقى المحادثة للقراءة فقط خارج بوابة تسليم المشاريع.
