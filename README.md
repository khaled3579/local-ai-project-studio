# Local AI Project Studio

برنامج محلي بواجهة عربية لإدارة النماذج وبناء المشاريع البرمجية على Windows. نسخة المصدر الحالية تحمل رقم `4.17.106` بحسب `release.json`.

## محتويات هذه النسخة

تحتوي على مصادر البرنامج وواجهاته ومشغلاته وملفات تعريف الاعتمادات. استُبعدت ملفات اختبارات التطوير وتقارير الفحص والسجلات والمحادثات والمرفقات وبيانات المشاريع والإعدادات الخاصة بالجهاز والبيئات المؤقتة وأوزان النماذج والمكونات الثنائية. بقيت أدوات التحقق والمعاينة والاستعادة التي يستخدمها البرنامج أثناء تشغيل مشاريع المستخدمين؛ حذفها يعطل وظائف البرنامج.

## التشغيل

هذه نسخة مصدر وليست حزمة تشغيل مستقلة. أرشيف GitHub لا يحتوي على `runtime` الثنائي أو `wheelhouse`. يلزم Windows x64 وPython 3.13 x64 مع pip وvenv وTkinter، ومكونات التشغيل المطابقة لـ `runtime-lock.json` وعجلات Python المطابقة لـ `requirements.lock.txt`. يجب تجهيز تلك المكونات قبل استخدام المشغلات؛ يرفض التحقق الاعتمادات الناقصة أو غير المطابقة.

يحدد `runtime/assistant/package-lock.json` أدوات Node المستخدمة: Playwright وPyright وTypeScript. تُثبت محليًا داخل هذا المجلد، والمتصفح في `runtime/browser`، وNode في `runtime/node`، ومحرك llama في `runtime`. راجع تعليمات التشغيل وحقوق المكونات المرفقة بالمصادر. لا تتضمن هذه النسخة أوزان النماذج أو Python أو تعريف NVIDIA.

بعد تجهيز نسخة التشغيل المطابقة:

1. شغّل `Start.cmd` أو `Daily-Projects.cmd`.
2. افتح واجهة المشاريع على http://127.0.0.1:18078 ومدير النماذج على http://127.0.0.1:18079.
3. اختر النموذج ومجلد مشروع مستقل وابدأ العمل.
4. احفظ تقدم المهام وأوقف تطبيق المشروع قبل إيقاف الخدمات باستخدام `Stop.cmd`.

قد يحرر `Start.cmd` المنافذ 18078 و18079 و18080 بإيقاف العمليات المالكة لها؛ راجع الرسائل قبل التشغيل. إغلاق المتصفح لا يوقف الخدمات.

## حفظ البيانات والاستقرار

تُنشأ بيانات الجهاز تحت `daily/` و`.environments/` و`.updates/`، وبيانات كل مشروع داخل `.local-ai/` في مجلده. لا ترفعها إلى مستودع عام ولا تحذفها لتحديث مصادر البرنامج. تتضمن وظائف البرنامج مراجعة المصادر ثم بناء الخطة تدريجيًا وربط أدلة القبول وحفظ نقاط الاستئناف.

يدعم المشغّل اختيار مفسّر منفصل لخدمة المشاريع من مسار داخل `.environments` عبر إعداد محلي `daily/studio-runtime.json`. تدعم الخدمات أيضًا سياسة اختيار أنوية الكفاءة عند إعداد `daily/service-cpu-policy.json` محليًا. لا تُنسخ هذه الإعدادات بين الأجهزة دون مراجعة. هذه وسائل تشغيل، وليست ضمانًا لإصلاح أعطال المعالج أو الذاكرة.

الخدمات محلية على 127.0.0.1. أوامر المشاريع تعمل بصلاحيات حساب Windows. نجاح الفحص لا يضمن تحقق كل سلوك أو تكامل خارجي؛ يجب مراجعة الأدلة الفعلية للمتطلبات.

لم تُرفع ملفات الاختبارات أو تقارير نتائجها في هذه النسخة النظيفة. لا تعتبر غيابها نجاحًا جديدًا للاختبارات. لا تستخدم أرشيف المصدر كحزمة تحديث ثنائية؛ احتفظ بنسخة بيانات واستعمل آلية التحديث والتحقق المناسبة للحزمة الكاملة.
