# Local AI Project Studio · 4.9.3

مساحة عمل محلية بواجهة عربية لبناء المشاريع البرمجية وإصلاحها باستخدام نماذج GGUF على Windows.

الإصدار الحالي للشيفرة **4.9.3**. راجع [ملاحظات الإصدار](RELEASE_NOTES_4.9.3.md) و[سجل التغييرات](CHANGELOG.md) و[ملخص التحقق المسجل](docs/validation-4.9.3.json).

## التشغيل

تحتاج نسخة التشغيل إلى Windows x64 وPython 3.13 x64 مع pip وvenv وTkinter، ومجلد قابل للكتابة، والمكونات الثنائية والعجلات المطابقة لـ`runtime-lock.json`. أوزان GGUF تُختار من مكتبة النماذج ولا تُرفق مع الشيفرة. يجب أن تناسب RAM وVRAM النموذج والسياق، مع تعريف NVIDIA المناسب عند استخدام GPU.

هذا المستودع ينشر المصادر والمشغلات والاختبارات الموجودة. **أرشيفا Source code لا يحتويان على runtime أو wheelhouse أو أوزان النماذج.** قد تضم [صفحة الإصدارات](https://github.com/khaled3579/local-ai-project-studio/releases) حزم تشغيل أقدم؛ رقم الحزمة هو مرجع نسختها، ولا يحولها تحديث الشيفرة إلى 4.9.3.

بعد تجهيز نسخة التشغيل الكاملة المطابقة:

1. شغّل `Start.cmd`، ثم افتح مساحة المشاريع على <http://127.0.0.1:18078/> أو مدير النماذج على <http://127.0.0.1:18079/>.
2. اختر مجلد نماذجك والنموذج والسياق، ثم شغّل النموذج.
3. افتح مشروعاً أو أنشئ مجلداً مستقلاً واكتب طلبك ومتطلباته.
4. أوقف المهام وتطبيق المشروع قبل تشغيل `Stop.cmd`. إغلاق المتصفح وحده لا يوقف الخدمات.

يمكن استخدام `Daily-Projects.cmd` و`Daily-AI.cmd` لفتح الواجهتين. عند استخدام `Start.cmd` تُفحص منافذ TCP المطلوبة **18078 و18079 و18080** ويُوقف مالكو المنافذ المشغولة قبل البدء، حتى لو كانوا لبرنامج آخر. يعرض المشغّل أسماء العمليات ومعرفاتها، ولا يغلق جميع عمليات Python أو Node. يطلب حفظ توقف مؤقت للمهمة النشطة في هذه النسخة قبل إغلاقها، ثم يمكن استئنافها من الواجهة. أوقف تطبيق المشروع أو الاستيراد أو الأداة اليدوية النشطة أولاً. لا يوقف خدمات Windows المحمية، ويتوقف بخطأ ظاهر إذا تعذر التحرير؛ قد تحتاج تشغيله كمسؤول.

## الإمكانات

- مكتبة نماذج محلية ومعلومات GGUF وسياق قابل للتعديل وتحكم MTP والخبراء عندما يدعمهما المحرك والنموذج.
- بث الرد وتقدم المهمة، وإيقاف واستئناف، وحفظ المحادثات والمسودات والمرفقات ومتطلبات المشروع.
- محرر ومقارنة ومعاينة، واستيراد ZIP إلى مجلد مستقل، وتصدير المصادر مع تقرير وتعليمات تشغيل.
- نسخ احتياطية ومحاولات إصلاح واستعادة تقدم السلسلة، مع إيقاف الأوامر الملتبسة للمراجعة دون إعادة تلقائية.
- قراءة مصادر بالرمز أو النطاق، ورقع تعتمد على بصمة القراءة الفعلية، وحماية الملفات من استبدالها بمقتطف أو إدراج تعريفات مكررة.
- فحص Python وJavaScript/TypeScript، وحفظ stdout/stderr والأخطاء وإيصالات الاختبارات المسماة.
- ربط المتطلبات بمعايير قبول واختبارات وأدلة مضيف مناسبة، ورفض الأدلة الناقصة أو القديمة.
- متصفح Chromium مؤقت لفحص HTML المحلي والأزرار والنماذج والأخطاء ولقطات الشاشة.
- بحث وتوثيق مرتبط بالإصدار، وقراءة Git وSQLite، ومقاييس توكن تُظهر القيم المفقودة دون اختلاقها.

## أحدث التصحيحات

**4.9.3:** فحص وتحرير منافذ TCP الثلاثة عند `Start.cmd`، والتحقق من خلوها قبل تشغيل الخدمات، ومنع تزامن عمليتي بدء، وإبقاء رمز الفشل الصحيح في CMD. يتوقف المشغّل إذا تبدل مالك المنفذ أثناء الإجراء أو منعت الصلاحيات تحريره.

**4.9.2:** حفظ رسائل المساعد أثناء التنفيذ وعرضها مع رسائل المستخدم، وإظهار المتابعات المرتبطة والمعاينات غير المكتملة، واستعادة الرسائل المتاحة فعلاً في سجل الاستعادة دون اختلاق رسائل مفقودة أو تكرار الرد النهائي. لا يتحول سجل العرض إلى سياق نموذج مكرر، ويُحافظ على موضع القراءة عند وصول تحديثات.


صحح 4.9.1 مؤشر الاستئناف قبل تهيئة النموذج وبعد دفعة أدوات مكتملة، ومزامنة الرد المعلّق عند الاستثناء، وقراءة سجل الاستعادة كلقطة SQLite واحدة مع فحص البصمات. يتضمن النشر أيضاً معالجة الأنواع في 4.9.0 وتحسينات القبول وحماية المصادر والسياق المتراكمة منذ 4.4.6.

## التحقق وحدوده

لم تُشغّل اختبارات جديدة لهذا النشر. الأدلة المحفوظة لـ4.9.2 تسجل صفر أخطاء أنواع وتحذيرات في17 ملفاً وصفر أخطاء صياغة في سكربتي الواجهة. شمل رصد المحادثة الموجودة فعلاً ظهور رسائل الطرفين دون إرسال محادثة تجريبية. تحقق4.9.3 اقتصر على محلل صياغة Windows PowerShell ومراجعة الشيفرة والبصمات؛ لم يُشغّل مسار تحرير المنافذ فعلياً ضمن التحقق. المتصفح المرئي لم يتوفر في بيئة مراجعة4.9.2، فلا يُدّعى تحقق بصري منه.


انخفضت ملاحظات Pyright الموروثة من **226 إلى صفر** في 4.9.0 ضمن 16 ملفاً. بقي النطاق نفسه في 4.9.1 بلا أخطاء أو تحذيرات، دون تعطيل المدقق أو إخفاء التشخيصات.

**لم تُشغّل اختبارات وظيفية أو تجارب نموذج أو قياسات توكن جديدة للإصدارين 4.9.0 و4.9.1.** اقتصر التحقق على مراجعة الشيفرة والأنواع وسلامة التثبيت المحلي وحفظ البيانات. اكتُشفت تصحيحات الاستعادة من مسارات الشيفرة دون اختبارات انقطاع جديدة. وجود ملفات الاختبارات لا يعني اجتيازها الإصدار الحالي. النتائج التاريخية ليست إثبات نجاح جديد أو ضمان توفير توكن أو أداء عام.

نجاح اختبارات مشروع لا يثبت شمول متطلباته؛ يجب أن تكون خريطة القبول حديثة وأن تناسب الاختبارات معاييرها. عقود الجودة والأداء إلزامية عند تهيئتها. معاينة HTML التشخيصية لا تثبت نجاح backend أو تكاملات خارجية حقيقية.

## الترقية والبيانات

أوقف المهام قبل الترقية واحتفظ بنسخة من بياناتك. استخدم حزمة تشغيل موثوقة مطابقة للإصدار وبصمتها وتعليمات `Update-App.ps1`/`Rollback-App.ps1` الخاصة بها. أرشيف Source code ليس حزمة تحديث تشمل المكونات الثنائية. لا تحذف نسخ الرجوع قبل التأكد من احتياجك لها.

بيانات التشغيل في `daily/` و`.environments/` و`.updates/`، وبيانات المشروع في `.local-ai/` داخل مجلده. لا تُنشر إعدادات جهاز أو محادثات أو مرفقات أو مشاريع مستخدم أو سجلات جلسات أو أوزان نموذج. لا تستبدل بياناتك ببيانات جهاز آخر.

الخدمات مرتبطة بـ`127.0.0.1`. متصفح الفحص لا يستخدم جلسات المتصفح الشخصية ويحظر الموارد الخارجية؛ أدوات Git وSQLite للقراءة فقط. كود المشاريع وأوامرها يعمل بصلاحيات حساب Windows؛ البرنامج ليس صندوق حماية لنظام التشغيل.
